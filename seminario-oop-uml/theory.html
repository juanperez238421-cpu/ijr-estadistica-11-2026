    LANGUAGE TRANSFER
    Python and Java express the same design differently.
    
      
    Python is concise and dynamic; Java makes types, visibility and contracts more explicit. The object model should remain recognizable in both. The embedded executable notebook uses Python/Pyodide so every student can run code directly in the browser.
    
      
    Python
    self, constructor __init__, convention-based privacy, duck typing.
    Java
    this, typed fields, explicit visibility, interfaces and declared return types.
