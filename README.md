## Colab Lab 01

Actividad formativa de transición entre sintaxis básica de Python y análisis de datos. Usa un notebook real de Google Colab, un CSV pequeño y ocho checkpoints corregibles. El progreso y la nota se registran mediante Supabase para mostrarse en el registro maestro.

Temas: variables, suma y multiplicación, listas, `len`, `sum`, promedio, lectura de CSV con Pandas, `DataFrame.shape`, `Series.mean` y filtrado básico.

El backend de esta actividad se versiona mediante la migración `supabase/migrations/20260819081500_colab_learning_activity_live_gradebook.sql`.
