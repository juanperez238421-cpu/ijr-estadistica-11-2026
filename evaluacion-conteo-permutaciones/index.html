Registro del estudiante

18 preguntas · 40 minutos · máximo 15 puntos.

Condiciones de integridad: la evaluación registra tiempos de respuesta, cambios de pestaña, pérdida de foco, salida de pantalla completa, intentos de copiar/pegar, conectividad y sesiones duplicadas. Al tercer cambio de pestaña confirmado, el intento se anula automáticamente y queda disponible para revisión docente. Las capturas de pantalla están prohibidas; un navegador normal no puede detectar todas las capturas del sistema operativo, por lo que se usa marca de agua personal y se registran las teclas/eventos que el navegador sí puede observar.

El grupo y el nombre identifican el intento. El sistema normaliza mayúsculas, acentos, orden de palabras y tolera errores menores de escritura cuando la coincidencia es inequívoca. Se conserva exactamente el nombre escrito para auditoría. Un error pequeño no crea una identidad nueva ni habilita un segundo intento.
