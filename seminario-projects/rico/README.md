# Rico: executable message-animation project

Open `index.html`, choose one of four classes, then Theory or Workshop.
The workshop reuses the existing OOP Colab Lab 01 stylesheet and guide/editor/
console layout. `worker.js` executes editable Python in Pyodide 0.27.7.
Python computes all frame geometry and text; `player.js` only renders that data.

## Four classes

1. Contract, Config, first visible frame and validation.
2. Scene composition with Heart, Flower and Message; geometry/time tests.
3. Self-contained HTML export and serialization tests; manual offline/USB QA.
4. Actual unittest suite, deliberate failure/correction and live modification.

Each class has its own Theory URL and editable Workshop cells. Later classes
restore required source from saved earlier cells and identify those dependencies
in the console. Drafts are local to the browser and isolated from the OOP lab.
No local execution is represented as a teacher approval or a Supabase grade.

## Downloads

- `mensaje-rico.html`: embeds current executed frames and the renderer. It has
  no network dependencies and can be opened manually from another folder/USB.
- `crear_mensaje.py`: standard-library Python generator with edited source and
  the last executed configuration; creates an offline HTML beside the script.
- `rico-mensaje.ipynb`: editable four-class source for a Python notebook.
- `rico-evidencia.json`: code, execution outputs/errors and manual evidence notes.

The browser notebook needs Internet to initialize Python. The offline HTML does
not initialize Python; it plays the result generated by the student's code.
Physical USB/target-machine behavior remains a student verification task.

## Verification

`Rico Message Colab QA` runs the real browser Python engine and every class,
checks Python errors/recovery, parameter modification, mobile layout, assigned
Rico navigation, Theory links, draft restoration and exported files. It opens
the standalone HTML with HTTP(S) blocked and runs the downloaded generator in
native Python. Artifacts contain a workshop screenshot and generated deliverables.

The editable Python runtime runs in a worker; a 60-second timeout terminates
the worker and allows retry instead of leaving the UI blocked by a loop.

## Guided animation and video
Class 1 now renders a moving text sequence. Generate animation restores prerequisites and displays the result. The next step unlocks after successful execution. HTML and WebM exports use actual Python frames; persistent save links remain available if the browser does not start a download. WebM recording takes the animation duration and requires a canvas/MediaRecorder-capable browser; HTML remains available otherwise.
