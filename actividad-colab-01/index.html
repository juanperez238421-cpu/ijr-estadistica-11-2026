Operations, data types and arrays.

This first class stays intentionally basic. Your team will work only with arithmetic operations, core Python data types, and lists/arrays with simple indexes. No loops, functions, conditions or Pandas are used in the graded stages.

Need a command reminder? Use the Python commands button in the top bar at any time. The reference includes arithmetic, powers, square roots, comparisons such as >=, logical operators, lists, sum(), len(), and common mistakes. Reference-only commands are available even when they are not graded in this class.
