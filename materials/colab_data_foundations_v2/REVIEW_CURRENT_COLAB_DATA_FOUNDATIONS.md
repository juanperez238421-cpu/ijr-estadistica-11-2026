## Main issues found in the frame audit

1. The video behaves as a rapid roadmap rather than a complete beginner lesson.
2. The Colab interface receives only one chapter, combining notebook name, runtime, Files panel, cell types, execution, and output.
3. Code is smallest in the scenes where students most need to copy it: upload, `read_csv`, missing-value cleaning, and conditionals.
4. The six-stage bottom ribbon is useful for continuity but competes with dense content in several scenes.
5. The performance-goal scene shows too many criteria simultaneously.
6. The final guided challenge lists eight actions, which encourages procedural copying instead of one coherent evidence chain.

## V2 corrections

- Longer reading pauses before transitions.
- Larger code and fewer instructions per cell.
- Three explicit evidence phases: understand, analyze, communicate.
- A two-stage variable-classification decision.
- A simplified Colab overview in the main lesson.
- A separate ten-part Colab interface explainer.
- Clearer upload, loading, cleaning, and conditional workflows.
- A four-step guided investigation instead of eight disconnected commands.
- Larger 3×2 closing workflow cards.
