# Google Colab Interface — Grade 11 Quick Reference

## Top bar

| Element | What it does | Student habit |
|---|---|---|
| Notebook name | Identifies the `.ipynb` file | Rename it before working |
| Connect | Starts the cloud runtime | Confirm the runtime is connected |
| Share | Controls access permissions | Use only the permission requested |
| Account icon | Shows the active Google account | Confirm you are using the correct account |

## Menus and commands

| Element | Use |
|---|---|
| File | Save a copy, download, or print |
| Insert | Add code or text cells |
| Runtime | Run cells, restart, reconnect, or run all |
| Tools | Open settings and preferences |
| + Code | Add an executable Python cell |
| + Text | Add headings, explanations, formulas, and conclusions |

## Left sidebar

The **Files** panel shows files available to the current runtime. A CSV uploaded there is normally temporary session storage. Keep the original file in Google Drive or on the local computer.

## Cell anatomy

### Text cell

Use for the research question, plan, formulas, interpretation, limitations, and conclusion.

### Code cell

Use for Python instructions. Run with the play button or **Shift + Enter**.

### Execution number

`[3]` means the cell was the third cell executed in the current runtime. It does not mean the cell is the third cell in the notebook.

### Output

The result appears directly below the code cell. Read it before continuing.

## Safe submission checklist

- Rename the notebook clearly.
- Run all cells from top to bottom.
- Resolve all errors.
- Keep outputs and graphs visible.
- Save a copy in Drive.
- Share with the requested permission.
- Submit the CSV when required.
